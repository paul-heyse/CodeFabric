# Evidence

State what was checked, with command, revision/date, relevant configuration, result,
and limits. Historical evidence may be reused when its inputs remain applicable.
A scoped check is not universal certification. Empty test selection and failing children
must fail. Types and reasoned review are valid for properties they establish.
Automate failures according to consequence, recurrence, and maintenance cost; no fixed
oracle quota, test-body shape, repeated-invariant rule, or proof table is required.
Runtime operation records describe actual work. Source edits use ordinary Git history.
