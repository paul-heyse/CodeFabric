# Optional skill evaluation

Use only for an explicit evaluation request. Agree on the behavior being compared,
choose representative tasks, and record conditions, outcomes, costs, and observed defects.
Use independent task results rather than artifact counts as the main signal.
Keep trials bounded and honor repository/user scope. This is not a gate for product work,
policy cleanup, or changing skill documents. Write only the report the task needs.
