# Targeted library investigation

Start with the question and relevant pinned manifests/local source. Use library navigators
for specific chapters. Probe uncertain APIs or behavior with the smallest useful example.
Use primary upstream documentation when local sources do not answer the question.
Report the supported capability, constraints, affected consumers, and evidence limits.
Consider custom-code displacement when relevant, without a mandatory capability survey,
principle score, upgrade, licensing review, or source-artifact pipeline.
A dependency change needs ordinary compatibility/source checks and reviewed lock changes.
