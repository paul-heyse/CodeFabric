This derived view maps the current v2.3 roadmap to active implementation plan v5. The plan remains
authoritative for exact dependencies, acceptance checks, proving commits, and decommission batches.
V2.2 WP31--WP36 and DB09--DB10 are retained proved substrate; v5 does not relabel their history.

| Stage | Packets | Current-suite boundary |
|---|---|---|

| startup reconciliation | WP44 | exact empty-head activation readback, decisive readiness, owned supervisor/daemon lifecycle, honest WP29/WP30 revalidation |

## Milestone map

| Milestone | Proved capability |
|---|---|
| M08 | synchronized v2.3 authority and independently reviewed expectations |
| M09 | exact startup/reconciliation plus target-coherent generated daemon contract |
| M10 | real installed modern FastMCP 4 delivery with guards, handles, completion, cancellation, isolation, and recovery |

No milestone is satisfied by file presence, an executor statement, a state label, a digest, a
framework inspection alone, or predecessor agreement. Its exact packet oracles and decommission
exits must pass at an ancestral proving commit and again at the certification HEAD.
