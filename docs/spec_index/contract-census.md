# Contract navigation

There is no hand-maintained contract census or mandatory runtime contract-registry compiler. The [selected domain documents](README.md) define semantic requirements; ordinary code types, Arrow schemas and runtime observations implement them. Current support and workspace coverage must not be conflated.

Stable released wire/identity allocations remain compatibility inputs. Runtime action records support explanation, diagnosis and recovery. Historical requirement IDs in old plans remain searchable references; their old oracle and artifact obligations are retired. Use the [production plan](../plans/codefabric_pragmatic_production_implementation_plan.md) for transition work and actual acceptance examples.
